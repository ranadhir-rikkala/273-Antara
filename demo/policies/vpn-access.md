# VPN Access Policy

Employees get VPN access automatically on their first day through the IT onboarding checklist.

Contractors must request VPN access through the IT helpdesk. A contractor's request needs approval from the contractor's sponsoring manager, and access expires after 90 days unless the manager renews it.

Everyone who uses the VPN must enroll in multi-factor authentication (MFA) with the company authenticator app before the first connection.

If the VPN is down, check the IT status page first, then report it to the helpdesk so the outage can be tracked as one incident.
