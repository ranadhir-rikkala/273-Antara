# Use of AI Tools with Source Code and Company Data

This policy applies to everyone, including contractors.

No, you may not paste source code into a public AI chatbot. Pasting source code, customer data, credentials, internal hostnames or security findings into public AI chatbots, or into any AI service hosted outside the company network, is not allowed.

Use Antara, the company's private assistant, instead. Antara runs entirely inside the company network, and no question, document or answer is sent to an outside provider.

AI coding assistants are allowed only in their company-approved, self-hosted configuration, with cloud features and telemetry turned off.

Pasting company source code or customer data into an unapproved AI tool is a security incident and must be reported to the helpdesk the same day.
