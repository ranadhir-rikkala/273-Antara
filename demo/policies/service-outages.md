# What to Do When an IT Service Is Down

This guidance applies to everyone, including contractors.

If email, the VPN, Wi-Fi, single sign-on or any other IT service is down, first check the IT status page at status.company.internal to see whether the outage is already known.

If it is not listed, report it to the helpdesk. Reports about the same system are merged into one incident, so you will get updates there.

If email is down, use webmail in the browser or send urgent messages in Slack until email is restored.

If the VPN is down, work on tasks that do not need internal systems, or use the office network if you are on site.

If Wi-Fi is down in the office, use a wired connection at any desk, or a phone hotspot for urgent work.

For a customer-facing outage, the helpdesk pages the on-call engineer, who must respond within 5 minutes.
