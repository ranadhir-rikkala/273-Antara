# Installing Software and Browser Extensions

This policy applies to everyone, including contractors.

No, you may not download and install apps such as Slack, Zoom or Chrome from the internet. Install apps only from the company software catalog in the Self Service app. To request software that is not in the catalog, open a helpdesk ticket with the business reason; the security team reviews it within 3 business days.

You may install browser extensions only from the approved extension list. Any other browser extension is blocked automatically.

Paid software licenses need approval from your manager before purchase.
